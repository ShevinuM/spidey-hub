# SpotifyPal

Personal tooling for Spotify, built to add features Spotify itself doesn't
provide: smart playlist sorting by audio features, a liked-songs-only
filter, and time-boxed (monthly/yearly) liked-song playlists.

## Stack
- Python, MongoDB (pyMongo)
- Spotify Web API via spotipy

## Status
in progress · smart-sort and liked-songs filtering implemented; monthly
stats and mood-based playlists planned
