# Sheldon

A portfolio-building assistant chatbot, built during a 2-day hackathon and
expanded afterward. Iterated through a custom-trained NLP model, then
Chatterbot, before settling on the OpenAI API with a JSON-based response
cache to cut API calls.

## Stack
- Flask backend, OpenAI API
- JavaScript/HTML/CSS frontend
- previously hosted on AWS Elastic Beanstalk

## Status
built · hosted demo no longer deployed (exceeded AWS free-tier limits)
