---
label: Session picker
hint: Ctrl-b w
order: 4
rows:
  - name: Move selection
    keys:
      - ↑
      - ↓
    desc: Moves the highlighted row across every listed session and window.
  - name: Collapse / jump to session
    keys:
      - h
      - ←
    desc: On a window row, jumps to its session; on an open session, collapses it.
  - name: Expand a session
    keys:
      - l
      - →
    desc: Expands a collapsed session to show its windows.
  - name: Switch
    keys:
      - Enter
    desc: Switches to the selected window or session and closes this list.
  - name: Close
    keys:
      - x
    desc: Asks to confirm, then closes the selected window or session.
  - name: Exit
    keys:
      - q
      - Esc
    desc: Closes this list without switching anything.
---
