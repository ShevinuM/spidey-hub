---
label: Employment Records
hint: window 2
order: 9
rows:
  - name: Move selection
    keys:
      - ↑
      - ↓
    desc: Moves the highlighted row up or down.
  - name: Open selection
    keys:
      - Enter
      - l
      - →
    desc: Opens the highlighted company, employment type, or role file.
  - name: Go up a level
    keys:
      - h
      - ←
      - Backspace
    desc: Moves up — from role files to employment types to companies.
  - name: Open a row
    keys:
      - click
    desc: Opens a company, employment type, or role file immediately.
  - name: Go up a level (mouse)
    keys:
      - click ../
    desc: Moves up one level.
  - name: Filter
    keys:
      - f
    desc: Enters filter mode on the > prompt below the list.
  - name: Filter prompt (mouse)
    keys:
      - click
    desc: Click the > prompt to enter filter mode.
  - name: Type to filter
    keys:
      - a-z
      - 0-9
    desc: Narrows the list to rows matching what you type.
  - name: Clear filter
    keys:
      - Esc
    desc: Clears the filter and exits filter mode.
  - name: Confirm filter
    keys:
      - Enter
    desc: Keeps the filter text and returns to normal browsing.
---
