---
label: Command search
hint: "?"
order: 12
rows:
  - name: Open
    keys:
      - "?"
    desc: Opens a searchable list of every command and shortcut.
  - name: Type to search
    keys:
      - a-z
    desc: Filters the list as you type.
  - name: Move selection
    keys:
      - ↑
      - ↓
    desc: Moves the highlighted row, wrapping around.
  - name: Run a command
    keys:
      - Enter
    desc: Runs the highlighted command and closes the list.
  - name: Reference row
    keys:
      - Enter
    desc: On a keyboard-shortcut row, Enter does nothing — it's reference only.
  - name: Close
    keys:
      - Esc
    desc: Closes the list without running anything.
---
